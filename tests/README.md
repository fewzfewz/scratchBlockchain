# Tests

Integration and feature test suite for validating the blockchain on a local testnet.

## Structure

| Path | Description |
|---|---|
| `localhost/scripts/` | Node.js SDK-based test scripts (send transactions, query state, SDK connect/wallet, check blocks, check metrics, generate valid tx) |
| `localhost/QUICKSTART.md` | 5-minute quickstart guide |
| `localhost/README.md` | 45+ tests across 11 phases (core, consensus, transactions, governance, staking, bridge, upgrades, monitoring, SDK, advanced, stress) |
| `comprehensive-test.sh` | Single-shell full end-to-end suite (15 test categories) |
